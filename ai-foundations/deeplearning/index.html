深度学习核心

草稿

从神经元到神经网络

深度学习的基本单元是人工神经元，它模拟生物神经元的工作方式：接收多个输入，加权求和后经过激活函数，产生一个输出。

将多个神经元按层组织，就构成了神经网络。“深度"学习中的"深"指的是网络的层数较多（通常超过 3 层）。

关键机制：反向传播

训练神经网络的核心算法。思路很直接：

  1. 前向传播：数据流过网络，得到预测值
  2. 计算损失：将预测值与真实值比较
  3. 反向传播：利用链式法则，从输出层向输入层逐层计算梯度
  4. 参数更新：用梯度下降更新权重

反向传播本质上是微积分链式法则的自动化应用，现代深度学习框架（PyTorch、TensorFlow）都内置了自动微分（Autograd）机制。

主要架构演进

卷积神经网络（CNN）

专为图像设计：通过卷积层自动提取局部特征，参数共享使模型高效。

  • 代表性模型：LeNet、ResNet、EfficientNet
  • 主要应用：图像分类、目标检测、语义分割

循环神经网络（RNN/LSTM）

处理序列数据（文本、时间序列）：通过隐藏状态传递历史信息。

  • 问题：长距离依赖时梯度消失/爆炸
  • 改进：LSTM、GRU 通过门控机制缓解此问题

Transformer（划时代）

2017 年 “Attention Is All You Need” 论文提出，彻底改变了 NLP 乃至整个 AI 领域。

核心创新：自注意力机制（Self-Attention），让每个位置都能直接关注序列中的任意其他位置，无需逐步传递信息。

→ 这是现代大模型（GPT、BERT、LLaMA）的基础架构，详见 大模型章节

工程实践

训练稳定性

技巧作用
Batch Normalization稳定各层激活值的分布
Layer NormalizationTransformer 中更常用
梯度裁剪防止梯度爆炸
学习率调度Warmup + Cosine Decay

常用激活函数

  • ReLU：max(0, x)，简单高效，是最常用的选择
  • GELU：平滑版 ReLU，Transformer 中广泛使用
  • Sigmoid/Tanh：输出层或门控机制中使用

框架选择

  • PyTorch：研究首选，动态图，调试方便
  • JAX：高性能，函数式编程风格，Google 生态
  • TensorFlow/Keras：生产部署，TFX 生态完整
