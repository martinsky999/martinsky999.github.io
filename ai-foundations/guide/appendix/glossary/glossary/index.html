词汇表 | Jimmy Song

AI 术语不只是“名词解释”，更是开发者理解智能世界的钥匙。用工程师视角，快速掌握核心概念与应用场景。

该词汇表用开发者熟悉的类比来解释这些 AI 概念，每个解释都简短直观，并说明应用价值。

神经网络相关概念

  1. **神经网络（Neural Network

    Neural Network（神经网络）

    受到生物神经网络启发的计算模型。 ）** ：像一个由无数"函数节点"组成的计算管道，输入数据逐层转换成结果。应用：图像识别、语音识别。
  2. **神经元（Neuron

    Neuron（神经元）

    神经网络中的最小计算单元，类似代码里的函数调用。 ）** ：神经网络中的最小计算单元，类似代码里的函数调用。应用：决定输入数据的某个特征是否重要。
  3. **深度神经网络（Deep Neural Network

    Deep Neural Network（深度神经网络）

    层数很多的神经网络，像多层微服务串联。 , DNN）** ：层数很多的神经网络，像多层微服务串联。应用：处理复杂任务如自动驾驶。
  4. **感知机（Perceptron

    Perceptron（感知机）

    最早的神经网络模型，像单层 if-else 判别器。 ）** ：最早的神经网络模型，像单层 if-else 判别器。应用：简单分类。

模型训练与优化

  1. **动量（Momentum

    Momentum（动量）

    优化训练时的加速度，避免模型震荡。 ）** ：优化训练

    训练（Training）

    使用数据集调整模型参数的过程，使模型能够学习数据中的模式。 时的加速度，避免模型震荡，像 CI/CD 部署的缓存加速。应用：更快收敛模型。
  2. **梯度（Gradient

    Gradient（梯度）

    优化算法中指导参数更新的方向，表示函数变化最快的方向。 ）** ：指示模型该往哪个方向优化，像监控告警里的趋势箭头。应用：指导权重更新。
  3. **梯度下降（Gradient Descent

    Gradient Descent（梯度下降）

    一种用于优化神经网络的一阶迭代优化算法。 ）** ：用梯度一步步优化模型，像通过迭代修复 Bug。应用：训练大部分神经网络。
  4. **梯度裁剪（Gradient Clipping

    Gradient Clipping（梯度裁剪）

    限制梯度过大，避免训练爆炸。 ）** ：限制梯度过大，避免训练爆炸，像给容器设 CPU 限额。应用：保持训练稳定。
  5. **正则化技术（Regularization

    Regularization（正则化技术）

    防止模型过于复杂的训练技术，提升泛化能力。 ）** ：防止模型过于复杂，像 Kubernetes 里限制 Pod 的资源。应用：提升泛化能力。
  6. **权重（Weight

    Weight（权重）

    模型中可调参数，决定模型预测结果。 ）** ：模型中可调参数，像配置文件里的调优项。应用：决定模型预测结果。
  7. **初始权重（Initial Weight

    Initial Weight（初始权重）

    训练开始前的参数值，影响训练速度与结果。 ）** ：训练开始前的参数值，像系统的默认配置。应用：影响训练速度与结果。
  8. **过拟合（Overfitting

    Overfitting（过拟合）

    模型在训练集上表现好但泛化能力差的现象，通常由模型过于复杂或训练数据不足引起。 ）** ：模型学到太多"训练集细节"，像写死特定输入的 if-else。应用：导致泛化差。
  9. **欠拟合（Underfitting

    Underfitting（欠拟合）

    模型未能充分学习训练数据特征的现象，通常由模型过于简单或训练时间不足引起。 ）** ：模型太简单，没学到关键规律，像用正则表达式处理复杂 API。应用：预测不准。
  10. **归一化（Normalization

    Normalization（归一化）

    把输入数据缩放到统一范围以加快收敛。 ）** ：把输入数据缩放到统一范围，像统一 API 请求格式。应用：加快训练收敛。
  11. 训练（Training） ：用数据不断调整模型参数的过程，像教学生做题直到掌握规律。应用：图像识别模型在数百万张图片上训练。
  12. **调参（Hyperparameter Tuning

    Hyperparameter Tuning（调参）

    调整学习率、批次大小等超参数以提升训练效果。 ）** ：指调整模型中的超参数（不是模型训练自动学到的参数，而是人工设定的配置），比如学习率、批次大小、层数。就像部署服务时要配置 CPU 核数、缓存大小、线程池数量，这些设置会影响性能。应用：通过调参可以让模型收敛更快、准确率更高，比如在训练推荐系统时找到最佳学习率组合。

数据处理与特征工程

  1. **张量（Tensor

    Tensor（张量）

    多维数组，AI 计算的基本数据结构，用于表示神经网络中的数据和参数。 ）** ：多维数组，类似 Kubernetes 里的 YAML，统一格式承载各种数据。应用：AI 框架的数据标准。
  2. **特征（Feature

    Feature（特征）

    描述数据的关键属性，用于训练模型。 ）** ：描述数据的关键属性，像数据库表里的字段，用于训练模型。应用：用"用户年龄、浏览记录"预测购买行为。
  3. **特征提取器（Feature Extractor

    Feature Extractor（特征提取器）

    自动挑选关键特征的模块。 ）** ：自动挑选关键特征，像日志解析器提取关键信息。应用：图像/文本分析。

机器学习基础

  1. **机器学习（Machine Learning

    Machine Learning（机器学习）

    一种数据分析方法，能让计算机自动从经验中学习。 ）** ：让计算机通过数据"自学"模式，而不是写死规则，像垃圾邮件过滤器通过大量邮件样本学会区分。应用：推荐系统、风控检测。
  2. **回归（Regression

    Regression（回归）

    预测连续数值的模型方法。 ）** ：一种预测连续数值的模型方法，像根据历史温度预测明天天气的具体温度值。应用：房价预测、销量预测。
  3. **聚类（Clustering

    Clustering（聚类）

    无监督学习方法，将相似数据自动分组。 ）** ：无监督学习的一种，把相似的数据自动分组，像电商把用户分成"爱买数码"“爱买美妆”。应用：客户分群、异常检测。
  4. **二分类模型（Binary Classification Model

    Binary Classification Model（二分类模型）

    只能输出两种结果的分类模型。 ）** ：只能输出两种结果，像 API 返回 true/false。应用：垃圾邮件识别。
  5. **遗传算法（Genetic Algorithm

    Genetic Algorithm（遗传算法）

    模仿生物进化的优化方法，通过选择、交叉、变异迭代。 ）** ：模仿生物进化的优化方法，用"选择、交叉、变异"不断迭代，像写代码时自动跑不同参数组合找最优解。应用：自动调参、路径规划。

深度学习模型架构

  1. **卷积神经网络（Convolutional Neural Network, CNN

    CNN（卷积神经网络）

    Convolutional Neural Network，常用于分析视觉图像的深度神经网络。 ）** ：专门处理图像的网络，像过滤器提取特征。应用：人脸识别。
  2. **循环神经网络（RNN

    RNN（循环神经网络）

    Recurrent Neural Network，一种专门处理序列数据的神经网络。 , Recurrent Neural Network）** ：能记住前后顺序的模型，像日志流处理。应用：语音识别、文本生成。
  3. **Transformer

    Transformer

    一种基于注意力机制的深度学习模型。 **：新型神经网络架构，靠"注意力机制"理解长依赖关系，像负载均衡器智能调度请求。应用：ChatGPT、BERT。

自然语言处理

  1. **自然语言处理（NLP

    NLP（自然语言处理）

    Natural Language Processing，人工智能的一个分支，致力于使计算机能够理解人类语言。 , Natural Language Processing）** ：让机器理解和生成人类语言。应用：ChatGPT、翻译。
  2. **命名实体识别（NER, Named Entity Recognition

    Named Entity Recognition（命名实体识别）

    从文本中识别和分类命名实体的任务。 ）** ：识别文本中的人名、地名、组织名。应用：信息抽取。
  3. **关键词提取（Keyword Extraction

    Keyword Extraction（关键词提取）

    从文本中找出核心词的任务。 ）** ：从文本中找出核心词，像日志关键词过滤。应用：搜索引擎。
  4. **文本聚类（Text Clustering

    Text Clustering（文本聚类）

    把相似文本分组的任务。 ）** ：把相似文本分组，像日志分桶。应用：文档分类。
  5. **机器翻译（Machine Translation

    Machine Translation（机器翻译）

    自动将文本从一种语言翻译成另一种语言的任务。 ）** ：让模型自动把一种语言转成另一种语言，像调用"语言转换 API"，输入英文返回中文。应用：跨境电商、文档翻译。
  6. **注意力机制（Attention Mechanism

    Attention Mechanism（注意力机制）

    让模型关注输入数据重要部分的机制，提升模型性能。 ）** ：模型会自动挑重点，就像读代码时先看核心逻辑，而不是逐字逐行。应用：提升翻译、文本生成质量。
  7. **嵌入

    嵌入（Embedding）

    将离散数据（如词语）映射到连续向量空间的表示方法。 （Embedding）** ：把文字、图片等复杂内容转化成一串向量（数字坐标），就像给每个词或图像生成"坐标地址"，方便计算机理解和比较。应用：语义搜索

    语义搜索（Semantic Search）

    基于语义理解而非关键词匹配的搜索方法。 、推荐系统。

计算机视觉

  1. **语义分割（Semantic Segmentation

    Semantic Segmentation（语义分割）

    将图像按像素划分为语义区域的技术。 ）** ：把图像按像素划分区域，像给 Kubernetes Pod 打标签。应用：自动驾驶车道识别。
  2. **ImageNet

    ImageNet

    大型标注图像库，常用于训练视觉模型。 **：大型标注图像库，像数据集的"GitHub"。应用：训练视觉模型。

强化学习

  1. **强化学习（Reinforcement Learning

    Reinforcement Learning（强化学习）

    通过试错来训练代理以最大化奖励的机器学习方法。 ）** ：模型通过"奖惩"学习，像游戏里的 AI 角色自我训练。应用：机器人、AlphaGo。
  2. **alpha-beta 剪枝（Alpha-Beta Pruning

    Alpha-Beta Pruning（alpha-beta 剪枝）

    减少搜索无用路径的剪枝方法。 ）** ：减少搜索无用路径，像缓存命中跳过无效请求。应用：国际象棋 AI。
  3. **深度强化学习（Deep Reinforcement Learning

    Deep Reinforcement Learning（深度强化学习）

    结合神经网络和强化学习的模型训练方法。 ）** ：结合神经网络和强化学习，模型通过"试错 + 奖励"学会策略，像训练游戏 AI 自己摸索最佳玩法。应用：自动驾驶、机器人控制。

AI 框架与工具

  1. **GPU

    GPU（图形处理器）

    并行计算利器，常用于深度学习训练。 （Graphics Processing Unit）** ：并行计算利器，像高性能分布式任务执行器。应用：训练深度学习模型。
  2. **TPU

    TPU（张量处理单元）

    Tensor Processing Unit，一种由 Google 开发的专用硬件加速器，用于机器学习。 （Tensor Processing Unit）** ：Google 定制的 AI 芯片，专为矩阵运算加速。应用：高效训练大模型

    大模型（Large Language Model）

    参数规模巨大的深度学习模型，通常指具有数十亿到数万亿参数的语言模型。 。
  3. **PyTorch

    PyTorch

    主流深度学习框架，提供灵活易用的模型开发接口。 （PyTorch）** ：一个主流的深度学习框架，提供"搭积木式"的 API，让开发者快速定义、训练和调试神经网络。它像是 AI 界的"Spring Boot"，既能研发新模型，也能直接跑在生产。应用：NLP 模型训练、计算机视觉任务、科研原型开发。
  4. **TensorFlow

    TensorFlow

    Google 开发的深度学习框架，适合大规模训练。 （TensorFlow）** ：Google 开发的深度学习框架，功能全面，适合大规模分布式训练，像是"企业级 AI 开发平台"。应用：语音识别、图像分类、推荐系统。

    只微调模型少量参数的方法，大幅降低训练成本和存储需求。 方法，只调整模型中少量参数就能让模型适配新任务，像给已有系统打补丁而不是重写。应用：小公司快速用大模型做定制。
