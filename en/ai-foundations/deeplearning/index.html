Deep Learning Core

草稿

From Neurons to Neural Networks

The basic unit of deep learning is the artificial neuron: it receives multiple inputs, computes a weighted sum, passes it through an activation function, and produces an output.

Organizing multiple neurons into layers forms a neural network. The “deep” in deep learning refers to having many layers (typically more than 3).

Key Mechanism: Backpropagation

The core algorithm for training neural networks:

  1. Forward pass: data flows through the network to produce predictions
  2. Compute loss: compare predictions with ground truth
  3. Backward pass: use the chain rule to compute gradients layer by layer
  4. Update parameters: use gradient descent to update weights

Backpropagation is essentially automated application of the calculus chain rule. Modern frameworks (PyTorch, TensorFlow) have built-in automatic differentiation (Autograd).

Architecture Evolution

Convolutional Neural Networks (CNN)

Designed for images: convolutional layers automatically extract local features; parameter sharing makes the model efficient.

  • Landmark models: LeNet, ResNet, EfficientNet
  • Main applications: Image classification, object detection, semantic segmentation

Recurrent Neural Networks (RNN/LSTM)

Process sequential data (text, time series) by passing hidden states to carry historical information.

  • Problem: Gradient vanishing/exploding for long-range dependencies
  • Fix: LSTM and GRU use gating mechanisms to mitigate this

Transformer (Paradigm Shift)

Proposed in 2017’s “Attention Is All You Need,” it fundamentally changed NLP and AI as a whole.

Core innovation: Self-Attention, letting each position directly attend to any other position in the sequence without sequential information passing.

→ This is the foundation of modern LLMs (GPT, BERT, LLaMA). See LLM chapter

Engineering Practice

Training Stability

TechniquePurpose
Batch NormalizationStabilize activation distributions across layers
Layer NormalizationMore common in Transformer models
Gradient ClippingPrevent gradient explosion
LR SchedulingWarmup + Cosine Decay

Common Activation Functions

  • ReLU: max(0, x) — simple and efficient, most common choice
  • GELU: smooth version of ReLU, widely used in Transformers
  • Sigmoid/Tanh: used in output layers or gating mechanisms

Framework Selection

  • PyTorch: research favorite, dynamic graphs, easy debugging
  • JAX: high performance, functional programming style, Google ecosystem
  • TensorFlow/Keras: production deployment, complete TFX ecosystem
