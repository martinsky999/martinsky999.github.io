Learning Guide

已完成

This section is designed for developers with an engineering background. The goal is to systematically organize the core knowledge required in the AI era. Content is organized around two main threads: theoretical foundations (Machine Learning → Deep Learning → LLM internals) and engineering practice (AI-native infrastructure).

Why This Guide?

AI knowledge is exploding, but most introductory materials fall into two extremes: either too academic (full of math proofs) or too shallow (just calling APIs). This section aims to take an engineer’s perspective — selecting and organizing content by the standard of “can be deployed, can be reproduced.”

Recommended Learning Path

Step 1: Machine Learning Fundamentals

From supervised to unsupervised to reinforcement learning — understand the underlying logic of AI. The focus is not on deriving algorithms, but on building intuition: knowing what tool to use in what situation, and why.

→ Go to Machine Learning

Step 2: Deep Learning Core

Neural networks, backpropagation, convolutional networks — these are the cornerstones of understanding modern AI systems. This chapter uses engineer-friendly analogies to unpack these concepts.

→ Go to Deep Learning

Step 3: Large Language Model Internals

Transformer, attention mechanisms, pre-training and fine-tuning, RLHF — master the full pipeline from LLM training to inference to truly leverage these models.

→ Go to Large Language Models

Reading Tips

  • Read sequentially: the three topics build on each other — start with machine learning
  • Practice as you read: each chapter includes recommended readings and hands-on links
  • Don’t need to cover everything: readers with engineering backgrounds can skim mathematical derivations and focus on architecture and implementation

Reference Resources

  • Jimmy Song’s AI Handbook — AI practice guide from a cloud-native engineer’s perspective
  • Andrej Karpathy: Neural Networks Zero to Hero — build neural networks from scratch
  • Fast.ai Practical Deep Learning — top-down practical approach
